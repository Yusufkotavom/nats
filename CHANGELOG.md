## [Unreleased] - 2026-05-08

### Added
- **2026-05-28 | Scope: Product Stock Mode + Inline Stock Sync from Edit** - Menambahkan mode produk `Manage Stock` (on/off) di form produk. Saat edit produk dengan mode ini aktif, user bisa set `Current Stock` per warehouse langsung dari form produk, dan sistem akan otomatis membuat `Inventory Movement` tipe `ADJUSTMENT` berdasarkan selisih stok saat save. **Impact:** setup stok awal atau koreksi stok kecil bisa dilakukan cepat dari edit produk tanpa keluar ke halaman adjustment, tetap tercatat sebagai movement resmi.

- **2026-05-27 | Scope: Onboarding Defaults (Payment Method + Feature Toggles OFF)** - Menambahkan auto-bootstrap payment method minimal per company setelah `Default Accounts` terpasang: otomatis dibuat 1 `Cash` + 1 `Bank` account (child dari akun default `CASH_ON_HAND`/`BANK`) dan langsung dimapping ke default payment profile. Implementasi memakai helper idempotent `ensureCompanyMinimalContacts` di transaction agar tidak membuat duplikasi tipe contact yang sudah ada. **Impact:** company baru langsung siap dipakai lintas modul sales/purchase/hr tanpa harus input contact dasar manual.
- **2026-05-27 | Scope: Communication Settings Preview/Test per Event** - Menambahkan kemampuan preview template per-event langsung dari `Admin > Settings > Communication`, termasuk tombol test ke WhatsApp (`wa.me`) dengan nomor tujuan input manual. **Impact:** admin bisa validasi isi template tanpa menunggu transaksi nyata.

- **2026-05-27 | Scope: Payment Method Single Source Page (`/payment-method`)** - Menambahkan halaman baru `Payment Methods` sebagai single source of truth untuk method pembayaran berbasis master `Cash & Bank`.
